# CASE 017 — Пропавшее послание

Однофайловая интерактивная детективная история на русском языке, персонализированная под Мусю и Звёздочку. Внутри: нуарное расследование, логическая загадка, кодовые имена, фрагменты ночных разговоров, дата-ключ `26.10.2026`, обратный отсчёт и личное письмо в финале.

Не требует сборки, сервера или базы данных: сайт работает как обычная статическая страница.

## Публикация через GitHub Pages
1. Создайте новый публичный репозиторий на GitHub, например `case-017`.
2. Загрузите `index.html` и `README.md` в корень репозитория.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, нажмите **Save**.
6. Через минуту-две сайт появится по адресу вида `https://ВАШ-ЛОГИН.github.io/case-017/`.

## Как изменить письмо или добавить видео
- Финальное письмо находится в блоке с `id="letter"` внутри `index.html`.
- Если хочешь добавить личное видео, положи `final-video.mp4` рядом с `index.html` и добавь в секцию `id="videoArea"` такой блок:

```html
<video controls playsinline preload="metadata" style="width:100%;margin-top:16px;border:1px solid var(--line)">
  <source src="final-video.mp4" type="video/mp4">
</video>
```

Затем загрузи обновлённые файлы в GitHub. Прогресс игры хранится в `localStorage` браузера на устройстве игрока.
